Sobre

Sobre a Autora

Mayumi é estudante de Ciências da Computação na FURB, atualmente na 3ª fase do curso. Este projeto foi desenvolvido para a disciplina de Programação Web I, com o objetivo de aplicar conceitos fundamentais de desenvolvimento web, consumo de APIs e construção de interfaces interativas.

Além do contexto acadêmico, possui experiência com construção de microserviços e manipulação de bancos de dados, o que contribuiu para uma compreensão sólida sobre arquitetura de APIs, organização de dados e lógica de aplicação.

Sobre o Projeto

A aplicação consiste em um sistema com CRUD completo (Create, Read, Update e Delete), integrando consumo de API REST, paginação de dados, notificações para tratamento de identificadores inexistentes e persistência utilizando LocalStorage.

O projeto foi desenvolvido utilizando Vue 3, com foco em organização de componentes, reatividade e boas práticas de desenvolvimento. A aplicação também apresenta responsividade, garantindo adaptação adequada a diferentes dispositivos.

Desafios e Aprendizados

Embora os conceitos de JavaScript, APIs e CRUD já fossem dominados, a utilização do Vue 3 representou um desafio inicial, especialmente na adaptação ao modelo reativo do framework. Com estudo e prática, foi possível estruturar corretamente os componentes e o fluxo de dados da aplicação.

Para garantir maior integridade das informações, foi utilizada a biblioteca Zod na validação dos dados de entrada e das respostas da API, reforçando a confiabilidade da aplicação.

Tecnologias Utilizadas

  • HTML5
  • CSS3
  • JavaScript (ES6+)
  • Vue 3
  • Fetch API
  • Zod (validação de dados)
  • LocalStorage
  • API REST
