Sobre

Este sistema foi desenvolvido para demonstrar um CRUD completo utilizando:

  • JavaScript Nativo (Vanilla JS)
  • Arquitetura MVC modular
  • LocalStorage como persistência local
  • Integração com API REST
  • Validação com Zod

A aplicação realiza operações de inserção, listagem, atualização e exclusão de funcionários.
