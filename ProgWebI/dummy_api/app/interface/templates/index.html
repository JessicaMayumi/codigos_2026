Sobre

Sobre a Autora

Mayumi é estudante de Ciências da Computação na FURB, atualmente na 3ª fase. Este projeto foi desenvolvido para a disciplina de Programação Web I, com o objetivo de aplicar conceitos fundamentais de desenvolvimento web utilizando JavaScript nativo e organização arquitetural.

A autora possui experiência com construção de microserviços e bancos de dados, o que contribuiu para uma compreensão sólida sobre APIs REST, manipulação de dados e organização lógica da aplicação.

Sobre o Projeto

A aplicação implementa um CRUD completo (Create, Read, Update e Delete), utilizando JavaScript Nativo (Vanilla JS) estruturado sob o padrão MVC modular. O sistema integra consumo de API REST, persistência com LocalStorage e organização separada entre Model, View e Controller.

A interface permite inserção, listagem com paginação, atualização e exclusão de funcionários, além de notificações para tratamento de casos como identificação inexistente.

Desafios e Aprendizados

O principal desafio esteve na organização da aplicação utilizando arquitetura MVC de forma modular, garantindo separação adequada de responsabilidades e manutenção do código.

Para reforçar a confiabilidade dos dados, foi utilizada a biblioteca Zod para validação das informações de entrada e das respostas da API, assegurando maior integridade e consistência no sistema.

Tecnologias Utilizadas

  • HTML5
  • CSS3
  • JavaScript Nativo (ES6+)
  • Arquitetura MVC Modular
  • Fetch API
  • Zod (validação de dados)
  • LocalStorage
  • API REST
